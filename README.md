# Nikon Picture Control Collection

自作ピクチャーコントロールの設定と簡単な思想メモです。

---

## TRACE_TONE-03

### コンセプト
写真は、目の前に反応した自分の痕跡です。  
その痕跡を、過剰な演出ではなくトーンで残します。

---

### 概要
TRACE_TONEは、色ではなく光と階調によって空気を描写するためのピクチャーコントロールです。
目の前の光の印象や空気を写すことを目的としています。

---

### 設計思想
- 黒は沈めつつ、潰さずに残す  
- 白は持ち上げて余白を作る  
- 中間調は持ち上げて情報を残す  
- 色の主張をやや抑えるために彩度をやや抑制  

---

### レンズ前提（Nokton）
- 滑らかな階調  
- 開放付近の柔らかさ  
- 落ち着いたトーンバランス  

これらを活かしつつ、
- 階調 → 白黒レベルで強調  
- 柔らかさ → コントラストと輪郭で補強  
- 色 → 彩度を抑えて整理  

---

### 設定値
```
ベース：フレキシブルカラー
ピクチャーコントロール：TRACE_TONE-03

輪郭強調：+1.5
ミドルレンジシャープ：+0.5

明るさ：+0.5
コントラスト：+6
ハイライト：-24
シャドー：+15

白レベル：+35
黒レベル：-40

色の濃さ（彩度）：-2
```
---

### WB運用（例）
- 色温度：5200K〜6200K  
- WBシフト：B 0〜+1 / G 0〜+1  
WBで色のトーンを調整することで様々な表現ができます。
